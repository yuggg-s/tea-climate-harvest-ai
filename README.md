# AI驱动梅家坞气候智慧茶园：基于图像识别与积温模型的茶叶采摘窗口期决策系统
> AI4Climate全球青年气候解决方案挑战赛参赛项目
> One Place: 杭州梅家坞茶园
> One Climate Problem: 气候变化造成春季气温波动，茶树积温不稳定，茶农依靠人工经验难以精准判断一芽一叶采摘窗口期，影响龙井茶叶品质与收益
> One AI Solution: YOLOv8图像识别 + 田间气象积温融合决策系统

## 项目简介
气候变化使梅家坞春季气温波动加剧，茶树有效积温积累不稳定。传统方式依赖茶农经验判断采摘时间，容易出现采摘过早产量低、采摘过晚芽叶老化的问题。

本系统融合**计算机视觉目标检测**与**气象积温模型**：
1. 使用YOLOv8识别茶园实拍图片，统计「一芽一叶」茶芽数量；
2. 读取田间气象CSV数据，基于日均气温计算茶树生长积温；
3. 结合图像茶芽生长状态与积温条件，自动生成采摘窗口期建议，为梅家坞茶农提供直观、可落地的气候适应性决策辅助工具。

本项目为可运行Web Demo，使用Gradio搭建网页界面，非专业用户（茶农）可直接上传图片与气象文件，一键获取结果。

## 环境部署
### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动 Web Demo
```bash
python app.py
```
启动后访问本地网页链接，即可打开系统界面。

## 使用方法
1. 上传茶园现场实拍图片；
2. 上传气象 CSV 文件（字段：`date, temp_avg, temp_max, temp_min, humidity`）；
3. 点击运行，系统输出：茶芽检测数量、累计积温、采摘建议。

>说明：本 Demo 使用 120°C·d 作为演示阈值，实际阈值可通过参数配置

## 数据集与模型说明
- 图像数据集：Roboflow Universe公开数据集 teaRob（1733 张茶园实景图像，单类别`tea_bud`：一芽一叶，YOLO格式标注，CC BY 4.0开源许可）。数据按约7:3划分为训练集（1205张）与验证集（491张）。
- 模型：YOLOv8，训练后权重文件放在`models/best.pt`；
- 气象数据：杭州历史气象观测数据。
